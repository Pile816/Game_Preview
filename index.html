💰 如何取得遊戲幣

實況主開啟發薪狀態後，系統會依設定時間，定期發放遊戲幣給最近 30 分鐘內有發言的人。

📈 股市玩法

每個頻道都有自己的獨立股市。股價會定期自然更新，更新時間由管理員設定。

  • 自然波動
  • 隨機事件
  • 管理員觸發事件
  • 玩家大量買賣
  • 作空與回補
  • 爆倉
  • 軋空
作空後股票若持續上漲，空單可能爆倉；系統會強制回補空單，並可能造成股價進一步上漲。太多人作空但股價突然大漲時，也可能觸發軋空。

玩家指令

指令用途
!<幣名>查詢自己的錢
!錢包 !資產查詢自己的資產
!掛台查看掛台時間與今日獲得遊戲幣
!股市查看所有股票
!股 <股票代號>查看單一股票資訊
!買股 <股票代號> <股數>買入股票，手續費 2%
!賣股 <股票代號> <股數>賣出股票，手續費 2%
!持股查看自己的持股
!作空 <股票代號> <股數>建立空單
!回補 <股票代號> <股數>平掉空單
!空單查詢空單
⚙️

設定步驟

  1. 設定貨幣名稱與查詢指令
  2. 選擇發薪模式：manual 或 auto
  3. 設定發薪間隔、每次金額、每日上限
  4. 設定股市更新間隔
  5. 新增股票
  6. 測試 !股市、!測幣、!買股
🛠️

管理員指令

指令用途
!經濟 config查看目前設定
!經濟 set admins <user1>,<user2>設定管理員
!經濟 set currency_name <幣名>設定貨幣名稱
!經濟 set currency_command <幣名>設定貨幣查詢指令
!經濟 mode auto|manualauto：Twitch 偵測為上線後開始計時，每隔發薪間隔嘗試發放；離線後停止計時，下次開台重新開始。
manual：使用 !經濟 salary on / !經濟 salary off 控制是否發薪。
!經濟 set salary_interval_minutes <分鐘>設定發薪間隔
!經濟 set salary_amount <數量>設定每次發放金額
!經濟 set daily_salary_limit <數量>設定每日掛台獎勵上限
!經濟 set market_interval_minutes <分鐘>設定股市更新間隔
!經濟 set stock_market_enabled on|off啟用 / 停用股市
!經濟 set short_enabled on|off啟用 / 停用作空
!股市 new <股票代號> <股票名稱> <初始價格>新增股票
!股市 set <股票代號> price <價格>修改股票價格
!股市 set SHEEP name <名稱>修改股票名稱
!股市 set <股票代號> volatility <數值>修改波動率，0.06 代表股價自然更新時波動程度約 ±6%
!股市 set <股票代號> liquidity <數值>修改流動性；流動性越低，越容易被玩家大量交易影響價格
!股市 set <股票代號> float_shares <數量>修改流通股數
!股市 set <股票代號> enabled on|off啟用 / 停用股票
!股市 set <股票代號> shortable on|off允許 / 禁止作空
!股市 del <股票代號>刪除股票；會同步清除所有玩家該股票的持股與空單，不會補償玩家現金
!股市 event boom觸發市場上漲
!股市 event crash觸發股災
!股市 event <股票代號> good觸發個股利多
!股市 event <股票代號> bad觸發個股利空
!股市 tick手動更新股市
!<幣名> add <使用者> <金額>增加玩家貨幣
!<幣名> rm <使用者> <金額>扣除玩家貨幣
!<幣名> set <使用者> <金額>設定玩家貨幣
